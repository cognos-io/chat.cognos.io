# User-guide screenshots

This directory holds screenshots referenced by user guides.

Capture only synthetic Accounts. Hide Account Keys, OAuth tokens, email addresses, and other
personal data before saving an image.

Most Google sign-in screenshots are generated by
`e2e/tests/persona-elena.spec.ts` under `e2e/test-results/persona-elena/`.
The returning sign-in image is a focused capture of the login card. Keep these
stable names when refreshing the guide:

- `google-sign-in-register.png`
- `google-sign-in-emergency-kit.png`
- `google-sign-in-returning.png`
- `google-sign-in-connect.png`
